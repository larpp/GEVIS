# 검증 결과와 미검증 범위

## 실제 수행한 검증

Windows·Python 3.12 환경에서 수행했습니다. 원본 공정 데이터를 재학습하지 않았습니다.

| 항목 | 확인 결과 |
|---|---|
| 패키지 설치 | 편집 가능 설치 및 별도 경로의 배포 패키지 설치 성공 |
| 독립 실행 | 별도 설치 경로에서 합성 입력으로 768차원 특징 추출 성공 |
| 독립 패키지 시험 | 12개 통과. CPU·GPU, 결측·컬럼 오류, 합성 숫자 인코더 1회 학습·복원, 경로 이동, 배포 정보 누출 검사 |
| 현재 회귀 시험 | 삭제 후 36개 통과. ALD 전처리·계보·헤드 시험 24개를 포함하며 만든 입력 사용 |
| 기존·분리 모델 특징 | 같은 합성 입력과 가중치에서 CPU·GPU 최대 절대차 0 |
| 실제 DEP·융합 가중치 | 16시점 합성 입력·질문 3개에서 CPU·GPU 최대 절대차 0 |
| 저장 판별 헤드 | CVD 1개와 ALD 3개 로딩 및 정상 참조·합성 변화 추론 성공 |
| 배포본 검사 | 파일 목록 체크섬, Python 문법, 문서 상대 링크 검사 통과 |
| 현재 가중치 보호 | 이전 자료 포함 31개를 먼저 확인하고, 미사용 비교 결과 제거 후 최종 사용 자산 18개의 SHA256을 대조 |

위의 숫자 인코더 1회 학습은 시험용으로 만든 작은 배열의 API 확인이며 실제 공정 재학습이 아닙니다.
저장 헤드 실행은 센서 2개의 정상 참조 중간값과 한 센서의 합성 이탈 입력을 사용했습니다.
전체 Test F1을 다시 측정하거나 과거 헤드 예측의 완전한 일치를 확인한 결과는 아닙니다.

현재 검사 명령은 다음과 같습니다.

```bash
python -m pytest tests/portable -q
python -m unittest tests.test_ald_input_store tests.test_ald_run_lineage tests.test_ald_head_experiments -q
python -m unittest discover -s tests -p "test_*.py" -q
python scripts/verify_model_parity.py --saved-weights
python scripts/verify_saved_heads.py
```

기존 호환 코드 시험에는 `src`를 Python 모듈 탐색 경로에 추가해야 합니다.
마지막 두 명령은 비공개 가중치와 E5 파일이 필요합니다.
현재 실행 결과와 삭제 집계는 [정리 결과](cleanup_candidates.md)에 갱신합니다.

## 저장된 학습 지표로 작성한 그림

[공정별 학습 기록](training/README.md)은 체크포인트 이력을 읽어 만든 그림입니다.
실제 저장 가중치 선택 시점·검증 오차·Test 집계를 표시하며 재학습이나 새 평가를 수행하지 않았습니다.

## 미검증 항목

기존 인코더·융합의 전체 재학습, 전체 Run 성능 재평가, 증류와 0.50ms 목표 달성,
Linux 실장치 및 의존성까지 처음부터 설치한 완전히 새 환경은 미검증입니다.
기존 전체 학습 프로그램은 Python 문법 검사만 수행했으며 장시간 실행하지 않았습니다.
문서 그림은 운영 환경의 matplotlib DLL 문제를 피한 임시 렌더링 환경에서 생성했습니다.

로컬 노트북 결과는 보존하고 배포본에서만 출력을 지웁니다. 시험용 임시 파일도 실행 후 정리합니다.

## 노트북 실행 경로 확인

2026-11-05 현재 작업 폴더의 자산을 사용해 두 노트북의 실제 설정·모델 로딩·입력 준비 셀을
실행했습니다. 학습 함수는 검사 과정에서 호출할 수 없도록 막았으며 헤드를 재학습하지 않았습니다.

| 노트북 | 고정 인코더 수 | 지원 경로 | 준비 후 Run 수: 학습/검증/Test | 입력 구간 수: 학습/검증/Test |
|---|---:|---:|---|---|
| CVD | 6 | 6 | 68 / 16 / 16 | 2,081 / 488 / 491 |
| ALD | 1 (DEP.) | 37 | 36 / 14 / 18 | 12,319 / 4,188 / 7,068 |

ALD는 원본 CSV 173개를 모두 읽었습니다. 위 Run 수는 시간·구조 품질 검사와 경계 제거 후의
최종 준비 결과이며 처음 나눈 70/15/15 비율과 같다고 가정하지 않습니다.
노트북 첫 셀의 `WORKSPACE_PATH`로 코드와 자산 위치를 분리하며, 저장 모델 복원 셀이 해당
경로를 임의로 덮어쓰지 않도록 수정했습니다. 두 노트북 커널 이름도 `pecvd`로 통일했습니다.

```bash
python scripts/check_notebooks.py --prepare
python scripts/check_notebooks.py --source-root /path/to/cloned-code --workspace /path/to/assets --prepare
```

이는 준비 단계의 실제 실행 확인이며 노트북 전체 학습·전체 평가를 다시 수행했다는 뜻은 아닙니다.
소스 해시 호환성과 배포 체크섬이 줄바꿈 변환으로 달라지지 않도록 `.gitattributes`도 추가했습니다.
