# ALD 전처리와 입력 구간

이번 구조 정리는 전처리 정책을 변경하지 않습니다. 기존 결과와 비교할 수 있도록 원래 함수는
소스 해시가 유지되는 호환 계층에 남겨 두었습니다.

| 항목 | 현재 처리 |
|---|---|
| 원본 | `data/mt_nit/data_complete` 바로 아래 CSV |
| 사전 제외 | 기본값에서 열 개수·4/7월·레시피 이름으로 제외하지 않음 |
| 컬럼 | 전체 파일의 공통 이름 교집합. 일부 파일에만 있는 센서는 사용하지 못함 |
| 외부 전달 Test | 읽지 않으며 해당 Run 예약/제외도 하지 않음 |
| 구조 | Main/SubCycle·부모 Step·실제 loop·SubStep 순서 유지 |
| Run 분할 | 시각순 약 70/15/15; 분할 경계 시간 중첩 제거 |
| 센서 선정 | 공정 경로별 TRAIN에서 비수치·상수·관측 부족 제외; 최소 독립 Run 그룹 2개 |
| 밸브 | 기본 `ValveAct_` OPEN/CLOSE→1/0. 문맥만 제공하고 이상 주입·판별 대상에서 제외 |
| 상태 탐지 한계 | 이름이 다른 0/1을 자동 상태 처리하지 않음. 상수 밸브도 상수 제외 규칙 적용 |
| 정규화 | TRAIN median, IQR/1.349; 척도가 너무 작으면 std. ValveAct_는 0/1 유지 |
| 결측 | 보간·앞값·0 채움 없음. 실제 학습/평가는 필요한 입력이 완전한 Window만 지원 |
| 시각 품질 | TRAIN 관측 간격/허용오차 학습, 기본 최대 간격 1.5초 |
| 품질 실패 | Main 시각 실패는 Run 제외, SubCycle 구조/시간 실패는 해당 구간 제외 |
| 입력 구간 | TRAIN 길이 기반, 최대64 원본 시점, 패치 배수. 구간 길이만큼 이동하고 마지막 꼬리 추가 |
| 메모리 | 원본 센서 행렬은 디스크 캐시; 정규화된 구간 배열은 메모리에 존재할 수 있음 |

`PREPARED`는 위 결과인 Window 배열·센서/정규화 메타데이터·Run 분할·지원/제외 표·입력 식별자입니다.
학습된 가중치나 전달용 Test를 뜻하지 않습니다. `FEATURE .../N`의 N은 특징 벡터 차원이 아니라
특징 추출할 사례 수이며 공정·센서·지원 조건·주입 수에 따라 달라집니다.

CVD는 기존 CSV 체크섬·저장된 표준화 구간·Run 분할을 보존합니다. ALD와 동일한 원본 CSV
파서로 통일한 것이 아닙니다. 새 범용 `SensorNormalizer`는 유한한 연속값 배열 전용이며,
ALD 밸브 처리/공정 계층/Run 분할을 대신하지 않습니다.
