# 모델 구조와 입출력 규약

`GEVIS_Model`은 `pecvd`, 노트북, 제조 데이터 경로, 판별 헤드를 가져오지 않습니다.
기존 텐서 연산을 독립 모듈로 추출했고 같은 가중치 이름과 차원을 유지합니다.

1. 시계열 인코더는 원본 시점의 다중 스케일 모델입니다. 패치 길이 4, 잠재 차원 96이며,
   시간·센서 어텐션과 국소·전체 문맥을 결합합니다. 센서 개수가 바뀌는 입력 전이를 지원합니다.
2. 현재·참조 잠재 표현 4개 블록 384차원과 시간·센서 관계 정보를 합쳐 440차원 수치 토큰을 만듭니다.
3. 질문과 센서·시간 설명은 E5-small-v2와 학습된 투영을 거칩니다. E5 본체는 고정됩니다.
   외부 가중치 없는 최소 예제에서는 미학습 바이트 인코더를 쓰므로 기존 E5 성능을 의미하지 않습니다.
4. 질문이 수치·센서·시간 토큰을 교차 어텐션으로 조회합니다.
5. 기존 가중치의 융합 폭은 192입니다. 융합 응답·질문·선택 센서·국소 문맥 4블록으로 768차원입니다.
6. FDC는 MIN 경계와 MAX 경계에서 각각 얻은 768차원, 범위 통계 8개, 시간 정보 2개를 결합해
   1,546차원을 만듭니다. 이는 선택적 판별 과제의 특징 조립이며 독립 인코더 출력과 구분합니다.

기존 헤드는 특징 정규화 버퍼, 공통 MLP, 답변별 출력층입니다. BOOLEAN은 2개,
CHOICE 저장 출력은 정상 인덱스 포함 6개이며 양성 유형 비교는 5개, ORDINAL은 5개입니다.
BOOLEAN 양성일 때 유형·정도를 해석합니다. 그룹 방식은 양성 유형을 묶고,
Sigmoid 방식은 양성 5개 점수를 독립적으로 계산합니다.

고정된 인코더·융합이라는 말은 현재 헤드 학습에서 갱신하지 않는다는 뜻입니다.
기존에 CVD 데이터로 학습하지 않았다는 뜻이 아닙니다.
실제 공정별 복원 학습은 [학습 기록](../training/README.md)을 참고하세요.

README 구조도는 사용자가 제공한 그림의 구성을 SVG로 재현한 것입니다.
그림의 CHOICE 6개는 정상 인덱스를 포함한 저장 출력 수이며, 양성 변화 유형 비교는 5개입니다.
