## 삭제한 항목

| 구분 | 처리 내용 |
|---|---|

| 중복 문서 | `_blueprint`, `_docs`, `_evidence`, `_meta`, `_note` 제거. 설계 변경은 `FAILURE_LOG.md`에 통합 |
| 보관본·중간 배포본 | 이전 노트북 보관본·중복 가중치 백업·중간 배포본 삭제 |
| 임시 산출물 | 오래된 바이트코드·빌드 메타데이터·시험 산출물 정리 |

추가 설정 파일과 이번 작업의 임시 도구·영수증 파일 삭제는 자동 승인 검토에서 차단됐습니다.
넓은 일괄 삭제와 경로를 명시한 비재귀 삭제 모두 `blocked by policy`로 거절되어 우회하지 않았습니다.
`config`의 이전 실험 설정·선택 의존성 파일과 `scripts`의 작업용 로컬 영수증·일회성 정리 도구는
따라서 아직 남아 있습니다. 모든 파일을 삭제했다고 표현하지 않습니다.
삭제한 경로 수는 파일 수와 다르며, 폴더 안의 파일을 별도로 중복 집계하지 않습니다.

## 남긴 항목과 이유

- `data`: 원본 데이터입니다. 수정·삭제하지 않았습니다.
- `artifacts`: 현재 인코더 6개·융합·CVD/ALD 헤드와 필요한 목록·입력 구간만 유지합니다.
- `.cache/ald-native-inputs`: 현재 코드와 일치하는 원본 CSV 173개분의 디스크 입력입니다.
- `.cache/ald-experiment-features`: 현재 저장된 CVD·ALD 헤드와 원본·정상 참조 식별자가 일치하는 6개 저장소만 남깁니다.
- `src/pecvd`: 기존 가중치의 해시 호환과 실행에 필요한 80개 모듈입니다.
- `GEVIS_Model`, `heads`, `examples`, `notebooks`, 현재 설정·문서·회귀 시험은 실행에 필요합니다.
- `.gitlab-release`: GitLab용 전체 예제와 독립 인코더 배포본 두 개만 둡니다.

현재 사용 모델 자산 **18개**의 체크섬을 유지했습니다. 이전 광범위 삭제 직후에는 관련 이전 자료를
포함한 31개를 확인했으며, 그중 사용하지 않는 비교 결과 13개를 추가로 제거했습니다.
저장 모델을 새로 학습하거나 원본 CSV를 고친 작업은 없습니다.

수치 집계는 [정리 집계 JSON](cleanup_report.json), 검증 범위는 [검증 기록](verification.md)에 있습니다.
